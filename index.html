評分方式

法人當日買超 ÷ 5 日均量（達 20% 滿分）25
法人 5 日累計買超 ÷ 5 日均量（達 50% 滿分）25
外資、投信連續買超天數（取較大者，5 天滿分）10
千張大戶持股比例週增減（+0.5 個百分點滿分）25
融資餘額減少（單日減少 3% 滿分）15
  • 法人買賣超單位為「張」（1 張 = 1,000 股），合計含外資、投信、自營商。
  • 負向數值（法人賣超、大戶減持、融資增加）該項得 0 分，不扣分。
  • 千張大戶 = 集保持股 1,000,001 股以上者的持股比例，每週更新一次。
  • 「隔日沖賣壓」為推估：當日漲 5% 以上、量為前 4 日均量 2 倍以上、收在高點附近，但法人未買超。
  • 融資餘額約在晚上公布，傍晚的資料會先顯示「部分資料尚未公布」。
  • 分數旁的 ▲▼ 是與前一個交易日相比的變化；「買盤聚集中」列出近 5 日分數上升最多的股票。歷史分數依當時的資料回算。

管理自選股

修改自選股需要一組 GitHub 金鑰，只要設定一次，金鑰只存在這台裝置的瀏覽器中。

  1. 打開 GitHub 建立金鑰頁面（Fine-grained token）
  2. Token name 隨意填，例如 stock_watch；Expiration 可選 No expiration 或一年
  3. Repository access 選 Only select repositories，勾選 stock_watch
  4. Permissions → Repository permissions → Contents 設為 Read and write
  5. 按 Generate token，複製以 github_pat_ 開頭的金鑰貼到下方
這組金鑰只能修改這個 repo。換裝置時需要重新貼一次，也可以隨時到 GitHub 刪除它。
