先完成一次設定 ☕

證交所的即時報價不允許網頁直接讀取，需要一個小小的「轉送站」幫忙轉一手。轉送站只會轉送股票代號和報價，不會經手你的持股資料。兩種方式擇一即可：

方式一：Cloudflare Worker（免費，推薦）
  1. 到 cloudflare.com 註冊免費帳號
  2. 左側選 Workers & Pages → Create → 建立 Worker（Hello World 範本）
  3. 按 Edit code，把 cloudflare-worker.js 的內容整個貼上，按 Deploy
  4. 複製畫面上的網址（例如 https://xxx.workers.dev）
方式二：放在自己的 PHP 主機
  1. 下載 proxy.php
  2. 上傳到任何支援 PHP 與 cURL 的主機
  3. 網址例如 https://你的網域/proxy.php

完成後按右上角的 ⚙ 轉送站，貼上網址並測試。
